# Branch Changelog: `android-fixes` (vs. `master`)

## 📱 Android Platform & Storage Access (SAF / VFS)

- **Storage Access Framework (SAF) File Renaming**:
  - Implemented `renameFile` in [FileManager.java](file:///D:/Akhenaten/android/akhenaten/src/main/java/com/github/dalerank/akhenaten/FileManager.java#L473) using `DocumentsContract.renameDocument` to support native Android document renaming over SAF.
  - Added JNI bindings `android_rename_file()` in [android.cpp](file:///D:/Akhenaten/src/platform/android/android.cpp#L220) and integrated it into `vfs::file_rename_os()` in [vfs.cpp](file:///D:/Akhenaten/src/content/vfs.cpp#L250).
- **File Descriptor Mode Parsing**:
  - Fixed file open mode handling in [FileManager.java](file:///D:/Akhenaten/android/akhenaten/src/main/java/com/github/dalerank/akhenaten/FileManager.java#L484) to correctly format mode flags (`"wt"` for truncation, `"wa"` for append).
- **User Directory Resolution**:
  - Improved user storage path resolution in `platform_resolve_user_directory()` inside [platform_android.cpp](file:///D:/Akhenaten/src/platform/platform_android.cpp#L61) using `SDL_GetPrefPath()` with fallback to internal storage or standard paths.
- **Gradle & Build Configuration**:
  - Updated [build.gradle](file:///D:/Akhenaten/android/akhenaten/build.gradle#L591) to support target ABI selection via `-PtargetAbi` property.
  - Configured debug builds to target `arm64-v8a`, `x86_64`, and `x86`, while release/CI builds compile `armeabi-v7a`, `arm64-v8a`, and `x86_64`.
  - Cleaned up ImGui source inclusion in [CMakeLists.txt](file:///D:/Akhenaten/android/akhenaten/src/main/cpp/CMakeLists.txt#L85).

## 🎨 Graphics, Renderer & Android Context Restoration

- **GPU Context Loss & Texture Recovery**:
  - Added `platform_renderer_invalidate_all_textures()` in [renderer.cpp](file:///D:/Akhenaten/src/platform/renderer.cpp#L1116) and `image_recreate_all_textures()` in [image.cpp](file:///D:/Akhenaten/src/graphics/image.cpp#L486) to restore texture buffers, custom render targets, and imagepak atlases upon `SDL_RENDER_TARGETS_RESET` or `SDL_RENDER_DEVICE_RESET` events in [akhenaten.cpp](file:///D:/Akhenaten/src/platform/akhenaten.cpp#L587).
  - Retained raw atlas pixel buffers in memory on Android (`#ifndef __ANDROID__`) inside [imagepak.cpp](file:///D:/Akhenaten/src/content/imagepak.cpp#L678) to enable on-the-fly GPU texture regeneration after app backgrounding or surface recreation.
  - Fixed array deletion memory leaks by using `delete[]` for temporary pixel buffers in [imagepak.cpp](file:///D:/Akhenaten/src/content/imagepak.cpp#L417).
- **Aspect-Ratio Background Image Scaling**:
  - Refactored `ui::textured::graphics_draw_background()` in [graphics.cpp](file:///D:/Akhenaten/src/graphics/graphics.cpp#L55) to automatically compute scale factors (`max(fit_x, fit_y)`) and center background images (>= 500x350) on screens with varying aspect ratios.
  - Converted raw image nodes to `background()` widgets across multiple UI script files ([ui_advisors_window.js](file:///D:/Akhenaten/src/scripts/ui_advisors_window.js#L50), [ui_mission_briefing_window.js](file:///D:/Akhenaten/src/scripts/ui_mission_briefing_window.js#L32), [ui_mission_end_window.js](file:///D:/Akhenaten/src/scripts/ui_mission_end_window.js#L23), [ui_scenario_selection.js](file:///D:/Akhenaten/src/scripts/ui_scenario_selection.js#L311), and [ui_scenario_selection_campaign.js](file:///D:/Akhenaten/src/scripts/ui_scenario_selection_campaign.js#L160)).
