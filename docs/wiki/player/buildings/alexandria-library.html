Alexandria's Library Cleo

Alexandria's Library (Great Library) is a large marble learning complex: portico, rotunda, and halls. Build on clear land (13×14). Guilds: Work Camp (clear/level), Stonemasons, and Carpenters (scaffolding). Not Artisans; materials are marble, timber, and late copper for the roof. Do not confuse with the city Library education building (papyrus + culture walker) — the monument does not need papyrus.

Placement

  • Entire footprint must be clear land (all green). No cliffs/rocks (unlike Pharos / Abu Simbel).
  • Only one unfinished Library at a time (#one_library_only).
  • Marble is not a place-gate; Storage Yards deliver once masons need it.
  • Footprint rotates 13×14 ↔ 14×13 with building rotation.

Construction

  • Work Camp peasants clear and level the site.
  • Stonemasons: foundation → floor → columns → roof body → copper roof finish.
  • Carpenters raise timber scaffolding on foundation/columns/roof phases.
  • Late phase: copper so the roof “glistens like the sun” (mine or import).
  • Visual order (GIF 20 frames): stakes → clear pad → foundation → walls/columns + scaffold → roof → copper gleam → finished.

Missions

Consumer mission 49 (A Beacon of Light / Ptolemy's Alexandria) — with Pharos; sandbox: m_128_alexandria.js.
